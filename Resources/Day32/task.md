## Task 32/40

In this exercise, you will explore Kubernetes Networking, container network interface(CNI), container runtime etc
> [!NOTE]
> If you do not already have a Kubernetes cluster, you can create a local Kubernetes cluster by following [Day06 Video](https://youtu.be/RORhczcOrWs)

### Task details
1. Perform the steps as per the video demo.
2. Find out which CNI plugin your cluster is using and where its configuration file is stored on the node.
3. Using `crictl`, list the containers running on a worker node and read the logs of the kube-proxy container.
