## Task 27/40

In this exercise, you will set up a multi node Kubernetes cluster on virtual machines using kubeadm

### Task details
1. Install a multi-node Kubernetes 1.36 cluster on virtual machines using kubeadm
2. It should have 1 master (control plane) node and 2 worker nodes
3. Install containerd, kubelet, kubeadm and kubectl on every node, and Calico as the network add-on
4. All the nodes should be in ready status after the installation
